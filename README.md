# MIMIRU（ミミル）ベータ版

**VR の中で完結する、VRChat のための AI アシスタント**（Windows 用・無料のベータ版）

- **字幕とライブ翻訳**：相手の声を字幕にして、自分の言葉に訳します（PC の訳をすぐ出し、AI の自然な訳に差し替え）
- **バブル翻訳**：自分の声を相手の言葉に訳して、頭の上（チャットボックス）に出します
- **インサイト**：会話の話題と要点を AI がまとめます
- **スキャン・アスク**：今の画面を見せて AI に質問できます（VR の中を撮って聞くこともできます）
- **リキャップ・メモリーズ**：その日の会話と写真をふり返るページを作ります（PC の中だけ）
- **VR の中で使える**：左手首のツールバーと、空間に置くメインパネル（SteamVR。Quest＋Virtual Desktop でも）

> ベータ版です。まだ不具合があるかもしれません。見つけたら [Issues](https://github.com/HiiragiVRClub/MIMIRU/issues) で教えてください。

## 動かすのに必要なもの
- Windows 10 / 11（64 ビット）
- **NVIDIA の GPU をおすすめします**（ない PC でも動きますが、字幕が遅く・不正確になります）
- AI の API キー（Claude・OpenAI・Gemini・DeepSeek のどれか 1 つ。AI を使う機能に要ります。使った分だけ料金がかかります）
- VR で使うなら SteamVR
- 空きの容量 10GB ほど（はじめての起動で、文字起こし・翻訳の部品をダウンロードします）

## 入れ方
1. 右の **Releases** から、いちばん新しい `MIMIRU_v〇〇.zip` をダウンロード
2. 好きな場所に展開（例：`D:\MIMIRU`。デスクトップやダウンロードのフォルダーは避けるのがおすすめ）
3. 中の **start.bat** をダブルクリック
   - はじめての PC では、日本語のセットアップの窓が開いて、必要な部品を入れます（10〜30 分）
   - 「Windows によって PC が保護されました」と出たら「詳細情報」→「実行」
4. 起動すると、はじめての案内が出ます。AI のキーを入れて、使う機能を選んでください

くわしくは zip の中の **はじめに.md** を見てください。

## 困ったとき
- ⚙ 設定 →「一般」→「困ったとき」→「**記録をまとめて書き出す**」で、うまく動かないときの記録を 1 つの zip にできます（API キーは伏せて入れます）
- 不具合は [Issues](https://github.com/HiiragiVRClub/MIMIRU/issues/new/choose) から教えてください
  - **Issues は誰でも見られます。** 記録の zip には質問の文が少し入ることがあるので、Issues には貼らずに、作者に直接（DM などで）送ってください
- 新しい版が出ると、起動したときにお知らせします。入れ直すときは、新しい zip を展開して、前のフォルダーの `config.json`・`settings.json`・`logs` を移してください

## アンインストール
⚙ 設定 →「一般」→「困ったとき」→ 細かい設定の「アンインストール（片付け）」で、ショートカットと SteamVR の登録を外してから、フォルダーごと消してください。

## 大切なこと
- **VRChat のアンチチート（EAC）に触れません。** 使うのはアプリ単位の音声の取り込み・VRChat 公式の OSC・ログの読み取り・画面の撮影・SteamVR の公式のしくみだけです（メモリの読み書き・MOD・ファイルの書き換えはしません）
- 字幕・会話の記録・写真は、すべてあなたの PC の中に残ります（音声は保存しません）。AI を使う機能は、その文や画像を選んだ AI の会社に送ります
- 「MIMIRU 品質向上プログラム」：どの機能を何分使ったかとエラーの場所だけを、1 日 1 回お知らせいただきます（字幕・質問・名前・キーは送りません）。⚙ でいつでもやめられます
